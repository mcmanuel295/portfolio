# Confidence Mmesoma — Portfolio

A responsive single-page portfolio website inspired by the reference screenshots. Built with plain HTML, CSS, and JavaScript—no build step or dependencies required.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server.

## Included

- Responsive layout with a desktop header and fixed mobile bottom navigation
- Scroll progress indicator, theme toggle, and back-to-top button
- Auto-scrolling technology ticker and expandable service details
- Project links to three of Confidence's public frontend repositories
- Contact links and accessible page landmarks

## Customize

Update the profile image URL in `index.html` if you want to use a different portrait. The contact links and project cards are also easy to edit in that file.
